# Desktop Snow ❄️

Интерактивный зимний оверлей поверх рабочего стола для **Windows 10/11** и **Linux (X11)**, написанный на C++ с использованием библиотеки **raylib**.

## Возможности
- **Сугробы и физика лавин:** снег накапливается на панели задач, нижней границе экрана и поверх открытых окон.
- **Сосульки:** нарастают на краях окон и разбиваются при падении.
- **Интерактив с мышью:** можно зачерпывать снег, лепить и бросать снежки (оставляют кратеры в сугробах), а также собирать снеговиков.
- **10 уникальных скинов снеговиков** и **снегоуборочная машина**, расчищающая сугробы.
- **Удобно для стримов и работы:** прозрачное окно поверх всех приложений.

## Управление: снеговики и снегоуборщик
- **Как слепить снеговика:**
  1. Выберите режим укладки снега (Shift+Ctrl или F8) на верхней панели или в меню программы.
  2. Зачерпывайте снег мышью, скатывайте снежные комья и ставьте их друг на друга, чтобы собрать снеговика.
  3. Чтобы сменить облик снеговика, переключитесь в режим выбора скина (**Skin**) и выберите один из **10 доступных скинов**.
- **Как вызвать снегоуборщика:**
  - Снегоуборщик выезжает **автоматически**, когда на экране накапливается много снега.
  - Чтобы вызвать снегоуборочную машину вручную в любой момент, нажмите F9.

## Скачивание и запуск
Готовые файлы находятся в разделе **Releases** справа:
- **Windows 10 / 11:** скачайте `snow.exe` и запустите двойным кликом — установка и дополнительные `.dll` не требуются.
- **Linux (Arch / X11):** скачайте `snow`, разрешите запуск (`chmod +x snow`) и запустите `./snow`.

## Сборка из исходного кода (Linux)
```bash
g++ snow.cpp -lraylib -lGL -lm -lpthread -ldl -lrt -lX11 -O2 -s -o snow
```
